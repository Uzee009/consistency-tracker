## 2026-06-05 — Mobile track kickoff

Decision to start a separate Android-only mobile track. iOS ruled out (no MacBook, no Apple Dev account). Same Flutter project, `mobile_` prefix on new mobile-only Dart files, shared code (sync, data, models) reused as-is. Design-first workflow: claude.ai Artifacts to produce mockups before any Flutter is written, because the desktop layout is not phone-shaped and a dry run would just show breakage we already expect. Motion polish deferred until app is stable end-to-end. Created `mobile_DEVELOPMENT_PLAN.md`, `mobile_CURRENT_MODULE.md`, `mobile_DESIGN_BRIEF.md`. M1 in progress.
